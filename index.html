Mavric · 2026 – present · Engineering lead

CommerceAssist AI: an AI support assistant for online stores

The problem
Online merchants answer the same shopper questions about shipping, returns and policies again and again. Generic chatbots make things up, and a wrong answer about a refund is worse than no answer.
The approach
  • Agentic core: a provider-agnostic agent layer on the Anthropic (Claude) and OpenAI SDKs, with local Llama support. Every chat and dashboard action runs through tool-calling agents across 20+ tools.
  • Retrieval per store: RAG on PostgreSQL + pgvector, so each store gets its own knowledge base. Tenant isolation is enforced in the database with row-level security.
  • Guardrails: answers are checked against their sources before they reach a shopper; prompt injection, data leaks and low-confidence answers are blocked, and personal data is redacted from logs.
  • Delivery: a spec-driven workflow with custom Claude Code agents and skills, MCP integrations for Jira and Railway, and test suites that must pass before every release.
Stack
TypeScript · Node.js (Fastify) · GraphQL · React · PostgreSQL · pgvector · Claude & OpenAI APIs · Railway
